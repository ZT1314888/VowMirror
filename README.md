# VowMirror

> 面向婚礼场景的私密双人 AI 形象与造型效果预览系统。纯本地无状态架构，支持双人合照智能适配、婚礼造型目录与 SSE 流式生成。

---

## ✨ 核心特性

- 🔒 **隐私优先与零持久化**：用户上传的照片与生成结果仅驻留当次处理内存，服务端不设素材持久化存储，不写人像日志，页面刷新即销毁。
- 👫 **双人合照智能感知**：基于多文件图像编辑协议，模型自动识别合照人物特征与身着角色，无须用户手动裁剪或标注。
- 👗 **精选婚礼造型与场地融合**：内置 30 套高质量婚礼服装造型目录；支持保留原始合照背景或自定义上传婚礼场地参考图。
- ⚡ **实时 SSE 流式进度**：服务端事件流（SSE）透明呈现多阶段处理状态，内置 10 秒心跳保活与超时熔断，支持用户随时主动取消。
- 🎫 **安全额度账本**：基于 SQLite 哈希记账的生成码防刷机制，严格控制单码并发（固定为 1）与每日调用额度，保障模型调用受控。

## 🚀 快速启动

运行环境仅需 **Docker Desktop**（Linux 容器引擎）与 **Docker Compose**，宿主机无须安装 Go、GoFrame 或 Node.js 环境。

### 1. 配置环境

复制环境变量模板，并配置生成码：

```sh
cp .env.example .env
```

在 `.env` 中通过 `TRYON_API_KEYS` 填入至少一个线下发放的生成码（推荐使用密码学随机串，如 64 位十六进制散列值；多个码以逗号分隔）。

### 2. 启动服务

在仓库根目录执行一键构建并启动：

```sh
docker compose up -d --build web backend
```

### 3. 访问系统

启动完成后，在浏览器中打开：

```text
http://localhost:3000
```

> **运行提示**：
>
> - 前端服务仅绑定本机回环地址（`127.0.0.1:3000`），后端 API（`8000`）完全位于内部网络，不向宿主机映射端口。
> - 访客可直接浏览造型目录并预览本地合照；点击生成前输入生成码，前端预检通过后才向后端发送照片。

## 🛡️ 架构设计与隐私边界

```text
[ 浏览器客户端 ]
       │  (本地回环 :3000 / 纯前端预览)
       ▼
[ Nginx Web 容器 ]
       │  (内部反向代理 / 95s 缓冲超时控制)
       ▼
[ GoFrame 后端容器 ] ──(哈希校验)──> [ SQLite 额度账本卷 ]
       │  (POST /v1/images/edits 多图装配)
       ▼
[ 外部图像生成服务 ] (仅按需调用，阅后即焚)
```

- **严格边界输入校验**：合照与场地图均在服务端强制校验真实格式魔数、像素完全解码、单图体积限制（≤8 MiB）、分辨率边长（256~8192 px）及总像素上限（2000 万像素）。
- **零痕迹内存生命周期**：照片传输仅存在于当次请求处理管道；处理完成、主动取消或发生异常时立即释放内存引用，不保留历史图库。
- **账本与防刷保障**：SQLite 账本仅存储生成码的不可逆哈希值、UTC 当日尝试次数与累计成功计数，绝不关联用户身份或图片数据。
